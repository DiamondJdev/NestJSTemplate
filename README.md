## Overview

This repository is a template for quickly starting a new [NestJS](https://nestjs.com/) project using TypeScript. It provides a solid foundation for building robust, scalable server-side applications.

## Getting Started

Install dependencies:

```bash
npm install
```

Run the application in development mode:

```bash
npm run start
```

For hot-reload (watch mode):

```bash
npm run start:dev
```

Build and run for production:

```bash
npm run start:prod
```

## Testing

Run unit tests:

```bash
npm run test
```

Run end-to-end tests:

```bash
npm run test:e2e
```

Check test coverage:

```bash
npm run test:cov
```

## Deployment

For deployment best practices, see the [NestJS deployment docs](https://docs.nestjs.com/deployment).

To deploy on AWS easily, use [NestJS Mau](https://mau.nestjs.com):

```bash
npm install -g @nestjs/mau
mau deploy
```
